# 问题处理与缺陷修复记录 (Issue & Defect Resolution Log)

本记录梳理了 OpenGuard 在研发与自测过程中发现并关闭的典型工程与技术缺陷，体现完整的缺陷溯源与回归验证闭环。

| 编号 | 发现阶段 | 问题描述 | 根因分析 | 修复方案与回归验证 | 状态 |
| :--- | :--- | :--- | :--- | :--- | :--- |
| **ISS-001** | 跨平台测试 | Windows 下 `SQLite` 历史数据库测试结束后删除临时目录报 `PermissionError [WinError 32]` | Python `with sqlite3.connect(...) as conn:` 仅管理事务提交/回滚而不自动关闭文件句柄 | 在 `AuditHistoryStore._connect()` 中改用 `contextlib.closing` / `try-finally conn.close()`，所有句柄测试通过后立即释放 | 已修复 |
| **ISS-002** | 自动脱敏回归 | 执行 `autofix --secrets --apply` 后复扫仍提示 `.openguard_backup/` 目录内的备份源码含密钥 | `is_path_excluded()` 规范化相对路径时误用了 `.lstrip("./")`，导致 `.openguard_backup` 开头的点号 `.` 被剥离而逃逸 `DEFAULT_EXCLUDE_DIRS` | 改为精确剥离 `./` 前缀（`_strip_dot_slash`），恢复后 `.openguard_backup/` 100% 被跳过，脱敏后密钥数量稳定降为 0 | 已修复 |
| **ISS-003** | 许可证识别 | 中文版“木兰宽松许可证，第2版”或全称 `GNU General Public License v3` 识别为 `UNKNOWN` | 签名匹配采用全条件 `all()` 要求同时出现中英文简称且 `normalize_spdx_id` 未覆盖全称拼写 | 升级为多变体特征组匹配 `any(all(...))` 并补充全称规范化映射，`test_detects_mulan_psl_and_mit_licenses` 与 `test_normalize_spdx_variants` 通过 | 已修复 |
| **ISS-004** | 数据库凭据规则 | 密码中包含 `@` 字符（如包含 `@` 的数据库口令）时无法命中 `OG-SEC-038` | 正则密码分组使用 `[^@\s]+` 过早截断含 `@` 符号的强口令 | 改用允许密码含 `@` 并锚定末尾 `@hostname` 边界的正则模式，兼容各类复杂数据库密码 | 已修复 |
| **ISS-005** | 仓库管理规范 | 示例靶场若直接保留嵌套 `.git` 目录会导致主仓库误识别为 Git Submodule | Git 对嵌套 `.git` 目录默认按未跟踪子模块处理，不利于校内 `git.hust.edu.cn` 克隆复现 | 将源码靶场 `examples/vulnerable_demo_repo` 与独立历史构建脚本 `examples/setup_demo_git_history.py` 解耦，既无嵌套子模块污染，又可一键复现历史幽灵密钥扫描 | 已修复 |
| **ISS-006** | 跨 Python 兼容 | Python 3.11 CI 容器清理远程仓库临时目录或 Python 3.10 解析 TOML 时存在兼容隐患 | `shutil.rmtree(..., onexc=...)` 仅支持 Python 3.12+，且 `tomllib` 仅内置于 Python 3.11+ | 新增跨版本 `_safe_rmtree()`（3.12+ 用 `onexc`，3.10/3.11 用 `onerror`），并为 `dependency_parser.py`/`license_analyzer.py` 补齐 `tomli` 回退与 `pyproject.toml` 条件依赖（`test_v29`） | 已修复 |
| **ISS-007** | 配置加载与复用 | 传入字符串路径调用 `load_config(".")` 报 `TypeError`；复用 `OpenGuardAuditor(cfg)` 扫描多仓时原地修改配置且未继承 `.openguard.yml` 策略 | `load_config` 未先强转 `Path(root_path)`，且 `_audit_local_path` 直接引用 `self.base_config` 并仅合并 `.openguardignore` | 入口统一 `Path(root_path)`；`_audit_local_path` 使用 `model_copy(deep=True)` 并完整继承 `policy`/`custom_rules`/`custom_sast_rules`（`test_v29`） | 已修复 |
| **ISS-008** | Pre-commit 门禁 | 执行 `openguard scan . --staged`（含 `pre-commit` 钩子）时全量扫描了工作区而非仅检查暂存区变更 | `cli.py` 设置了 `cfg.staged_only = True`，但 `OpenGuardAuditor._audit_local_path()` 未消费该标志 | 在 `_audit_local_path()` 中优先处理 `cfg.staged_only`，通过 `git diff --cached` 与 `git show :<file>` 精准隔离暂存区增量（`test_v41`） | 已修复 |
| **ISS-009** | 增量缓存编码 | 开启 `--cache` 扫描包含中文或 Unicode 文件名的仓库时抛出 `UnicodeEncodeError` | `compute_file_cache_key()` 对 `scanner_ns` 使用 `.encode("ascii")` | 改为 `.encode("utf-8", errors="replace")` 并新增端到端中文文件名 `.mjs` 缓存回归测试（`test_v39`） | 已修复 |
| **ISS-010** | 自动脱敏重构 | 对 `"openai_api_key": "sk-..."` 字典/JSON 键值对执行 `autofix --secrets` 时误将左侧键名替换为 `os.getenv(...)` | 正则 `re.search` 从行首匹配首个长度 ≥6 的引号串，命中了键名而非右侧密钥值 | 严格在 `:`/`=` 右侧定位值，并新增 `.env*` 未加引号凭据重构支持（`test_v33`） | 已修复 |
| **ISS-011** | 多阶段容器审计 | 多阶段 Dockerfile 前序阶段设置 `USER appuser` 后，最终阶段未设 `USER` 却漏报 `OG-DOCKER-002`；`FROM builder` 误报 `OG-DOCKER-001`；带端口私库 `registry:5000/app` 漏报未锁标签 | `DockerfileScanner` 未在每个 `FROM` 重置阶段用户状态且用全串 `":" not in img` 判断标签 | 跟踪 `AS <alias>` 阶段用户继承并在新 `FROM` 重置 `last_user`，按最后路径段判定镜像标签（`test_v32`） | 已修复 |
| **ISS-012** | ML Pickle 反汇编 | Pickle Protocol 4/5 使用 `MEMOIZE`/`PUT` + `BINGET` 备忘录向 `STACK_GLOBAL` 压入模块名时可绕过静态检测 | `inspect_pickle_bytes()` 仅维护连续 `str_stack`，未模拟 Pickle 备忘录寄存器 | 完整跟踪 `MEMOIZE`/`PUT`/`BINPUT`/`GET`/`BINGET` 操作码并补充 `marshal.loads`/`types.FunctionType`（`test_v30`） | 已修复 |
| **ISS-013** | 有效代码统计 | `openguard cloc` 统计 Python `"""..."""` 文档字符串未计入注释、`'''...'''` 无法闭合，且 `.github/` 被跳过 | `LANGUAGE_MAP[".py"]` 使用不同起止符 `("'''", '"""')` 导致闭合分支错位；目录过滤用 `not d.startswith(".git")` 误伤 `.github` | 为 Python 三引号对齐同符起止匹配，并将目录过滤改为精确 `d != ".git"`（`test_v38`） | 已修复 |
| **ISS-014** | Git Diff / 历史回溯 | `get_git_diff_added_lines()` 与 `GitHistoryScanner` 遇到已删除文件（`+++ /dev/null`）后未重置文件名且中文路径被八进制转义 | 未监听 `+++ /dev/null`/`diff --git` 重置 `current_file`，且未传 `-c core.quotepath=false` | 统一添加 `-c core.quotepath=false`、删除文件状态重置及子进程超时兜底（`test_v36`, `test_v40`） | 已修复 |
| **ISS-015** | 仿冒包误报 | PyPI 等价命名包（如 `python_dotenv`）与热门列表 `python-dotenv` 仅差 1 个分隔符而被误报为 Typosquatting | 热门包比对未按 PEP 503 将 `-`/`_`/`.` 统一归一化 | 为 PyPI 生态增加 PEP 503 归一化豁免，并将 OSV 批量查询扩展为 60 组件分块遍历（`test_v35`） | 已修复 |
